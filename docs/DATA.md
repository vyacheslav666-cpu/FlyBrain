# Данные: откуда, в каком виде, на каких условиях

Ни один из этих файлов не хранится в git. Команда `flybrain fetch-data` (коммит C2) скачивает их в `data/raw/` и сверит контрольные суммы (SHA-256) с таблицей ниже. Если сумма не совпала, значит файл изменился у автора, и команда остановится, а не продолжит молча. Адреса и суммы лежат в `config/sources.yaml`. Суммы текстовых файлов посчитаны от байтов, которые отдаёт GitHub, — см. D-024.

### 1.1. `Completeness_783.csv` — список нейронов модели

| Столбец | Тип | Смысл |
|---|---|---|
| *(индекс)* | целое 64 бит | номер нейрона в FlyWire (root ID), например `720575940660219265` |
| `Completed` | да/нет | нейрон проверен людьми (у всех строк «да») |

- 138 639 строк.
- **Порядок строк важен.** Номер строки (с нуля) — это внутренний номер нейрона в модели. На него ссылаются столбцы `*_Index` в файле связей.

### 1.2. `Connectivity_783.parquet` — связи

Формат Parquet — сжатая таблица, читается библиотекой pandas. Одна строка — одна пара «нейрон A → нейрон B», у которой есть хотя бы один синапс.

| Столбец | Смысл |
|---|---|
| `Presynaptic_ID`, `Postsynaptic_ID` | номера FlyWire отправителя и получателя |
| `Presynaptic_Index`, `Postsynaptic_Index` | их номера строк в `Completeness_783.csv` (0…138 638) |
| `Connectivity` | число синапсов в паре (от 1 до 2405) |
| `Excitatory` | +1 — отправитель возбуждающий, −1 — тормозящий |
| `Excitatory x Connectivity` | произведение двух предыдущих: «сила со знаком» |

- 15 091 983 пары, 54 492 922 синапса.
- 9 059 302 пары возбуждающие, 6 032 681 тормозящие.
- Порог по числу синапсов не применён: учтены даже одиночные синапсы, как в статье.
- Вес связи в модели = `Excitatory x Connectivity` × 0,275 мВ.

### 1.3. `Supplemental_file1_neuron_annotations.tsv` — что это за нейрон и где он

Текстовая таблица с разделителем «табуляция»; 139 248 строк; 31 столбец. Нужные нам столбцы:

| Столбец | Смысл | Пример |
|---|---|---|
| `root_id` | номер FlyWire (версия 783) | `720575940660219265` |
| `pos_x`, `pos_y`, `pos_z` | опорная точка на нейроне, в вокселях 4×4×40 нм | `109306, 50491, 3960` |
| `soma_x`, `soma_y`, `soma_z` | положение тела клетки, в тех же вокселях (у 21 144 нейронов пусто) | |
| `super_class` | крупный класс: `optic` 77 541, `central` 32 383, `sensory` 16 907, `visual_projection` 8 038, `ascending` 1 750, `descending` 1 303, `sensory_ascending` 612, `visual_centrifugal` 524, `motor` 110, `endocrine` 80 | `motor` |
| `cell_class`, `cell_sub_class` | уточнение: например `gustatory` / `sugar`, `mechanosensory` / `grooming` | |
| `cell_type` | тип клетки | `CB0701` (это MN9) |
| `hemibrain_type`, `synonyms` | другие имена из литературы | `Giant Fiber` |
| `side` | сторона **со стороны мухи** (`left`, `right`, `center`) | |
| `top_nt` | предсказанный медиатор | `acetylcholine` |
| `flow` | направление: `afferent` (вход), `intrinsic` (внутренний), `efferent` (выход) | |

**Перевод координат в микрометры:** x_мкм = `pos_x` × 0,004; y_мкм = `pos_y` × 0,004; z_мкм = `pos_z` × 0,04.

Мозг занимает примерно 90–900 мкм по x, 50–440 мкм по y и 0–280 мкм по z. Ось x идёт поперёк мозга, y — сверху вниз, z — спереди назад (приблизительно). Снимки зеркальные — см. D-011.
