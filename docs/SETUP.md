## 2. Чего не хватает

| Что | Зачем | Как поставить |
|---|---|---|
| **uv** (менеджер Python и библиотек) | одна команда ставит Python 3.12, PyTorch и всё остальное в папку проекта | см. команду ниже |

Больше ничего ставить вручную не нужно. Библиотеки проекта поставит `uv sync` в первом коммите (C1):
- PyTorch 2.14 с CUDA 13.0;
- Brian2;
- pandas, pyarrow;
- FastAPI, uvicorn.

Около 3–4 ГБ, но всё уже лежит в кэше `uv` после исследования, поэтому скачивать заново не придётся.

## 3. Команды

Откройте **PowerShell** (Пуск → набрать «PowerShell» → Enter) и выполните по одной.

**Шаг 1.** Поставить uv:

```powershell
winget install --id=astral-sh.uv -e
```

**Шаг 2.** Закройте окно PowerShell и откройте новое, чтобы оно «увидело» uv. Проверьте:

```powershell
uv --version
```

Должно напечатать что-то вроде `uv 0.13.x`.

**Шаг 3.** Посмотреть, что лежит в проекте:

```powershell
cd C:\Projects\FlyBrain
git log --oneline
```

Дальше — коммит C1 в новом чате (см. [PLAN_M1.md](PLAN_M1.md)). После него появится команда проверки машины `uv run flybrain doctor`.

## 4. Возможные сообщения, которые можно не бояться

- `error: Missing expected target directory for Python minor version link…` при установке Python через uv. Причина — кириллица в имени пользователя Windows. Python ставится и работает (проверено). Сообщение не мешает.
- `IMAGEIO FFMPEG_WRITER WARNING: … macro_block_size=16` при записи видео FlyGym (этап M2) — видео чуть увеличивается до кратного 16 размера. Это не ошибка.

## 5. Что было поставлено во время исследования

Записываю, чтобы ничего не было «тайком»:
- Python 3.12.15 через uv — в `C:\Users\Вячеслав\AppData\Roaming\uv\python\`, плюс ярлык `C:\Users\Вячеслав\.local\bin\python3.12.exe`.
- Кэш скачанных библиотек uv (~4,1 ГБ) — в `C:\Users\Вячеслав\AppData\Local\uv\cache\`. Можно очистить командой `uv cache clean`, но тогда C1 скачает всё заново.
- Папка `C:\Projects\FlyBrain\.research\` (~0,4 ГБ, не в git): черновые скрипты замеров, копия репозитория Shiu, таблица аннотаций, результаты пробных прогонов. Её можно удалить в любой момент.
- Временные окружения для проверок удалены.
